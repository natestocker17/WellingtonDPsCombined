# Planning spreadsheets

- `PlanningCrosswalk.xlsx` is the editable crosswalk used for the 23 September 2026 map build. The build also applies source-specific rules in the local GIS pipeline, including the Wairarapa mixed-layer split and Horowhenua `NPS_OVERLAY` field selection.
- `district-plan-source-layer-classification-inventory-20260922.xlsx` is a 22 September 2026 snapshot. It predates the 23 September overlay changes and should not be treated as a current map inventory.

These files are published reference copies. The source GIS pipeline and geodatabase are maintained outside this website repository.
